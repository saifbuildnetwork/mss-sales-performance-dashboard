# 📊 MSS Sales Performance Dashboard

An interactive Power BI dashboard designed to analyze sales performance, profit, customer insights, and order trends. This project helps businesses monitor key performance indicators (KPIs) and make data-driven decisions.

---

## 📌 Project Overview

The dashboard provides a complete overview of business performance by tracking:

- 💰 Total Profit
- 📈 Total Sales
- 📦 Total Quantity Sold
- 🚚 Average Delivery Days
- 🛒 Sales by Category
- 👨‍💼 Sales by Salesperson
- 📅 Monthly Sales & Profit Trend
- 💳 Sales by Payment Mode
- 📦 Sales by Order Status
- 📉 Discount vs Sales Analysis
- 📊 Profit by Sub-Category
